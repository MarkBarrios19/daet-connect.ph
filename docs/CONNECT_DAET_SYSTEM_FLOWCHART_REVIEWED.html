System Flowchart

A simplified, readable version with direct step arrows, separate decision branches, and no crossing or duplicated connector lines.

01 Overview 02 Booking & payment 03 Operator & packages 04 Guide workflow 05 Admin workflow 06 Shared services

How to read this version

Each down arrow means one next step. A decision is split into labeled YES/NO (or method) cards. Cards in a task menu are independent choices, not a sequence. Shared databases and external services are shown separately so their links do not cross the user workflow.

  • Booking is created as pending; the operator confirms or declines it before payment.
  • Payment and tour check-in are separate processes. QR and roster check-in join at one server-side validation step.
  • Operator dashboard tasks and admin task types are not connected as one long chain.
